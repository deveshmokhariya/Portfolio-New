# Devesh Mokhariya - Portfolio Website

A responsive, recruiter-focused portfolio built using HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy for free

### GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings > Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`, then save.

### Netlify
Drag and drop this entire folder into Netlify's site deployment page.

## Customize

- Replace the `DM` initials in `index.html` with a profile image when available.
- Verify each project repository URL before deployment.
- Keep `assets/Devesh_Mokhariya_Resume.pdf` updated whenever the resume changes.
